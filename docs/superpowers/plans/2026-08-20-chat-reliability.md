# Chat Reliability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ensure incomplete evidence and semantic disagreement never become chat HTTP 503 responses.

**Architecture:** Preserve the generalized evidence flow while converting normal domain gaps into typed values. Keep 503 exclusively for exhausted required dependency failures.

**Tech Stack:** Python 3.12, FastAPI, LangGraph, Pydantic, pytest, AWS Bedrock

## Global Constraints

- Final successful chat prose is generated by Bedrock.
- Evidence planning and collection are read-only.
- Jira writes remain proposal/approval/verification operations outside chat.
- Missing evidence is data, not an exception.
