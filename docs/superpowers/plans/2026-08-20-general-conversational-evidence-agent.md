# General Conversational Evidence Agent Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace fixed-intent-controlled chat evidence gathering with a Bedrock evidence-category planner and optional-safe UniversalEvidenceBundle so new valid workforce questions work without adding phrases to source code.

**Architecture:** Every authenticated chat request resolves structured references, validates a Bedrock `EvidencePlan`, runs mapped allowlisted read collectors, derives deterministic calculations/rankings, and sends one universal bundle to Bedrock for final prose. Generic grounding and completeness validate the answer; missing evidence becomes typed data, while the proposal/approval/write saga remains isolated.

**Tech Stack:** Python 3.12, FastAPI, Pydantic v2, LangGraph, Amazon Bedrock Converse API, Atlassian Rovo MCP, Workforce Risk MCP, pytest, Ruff.

## Global Constraints

- Every successful user-visible chat answer is generated by Amazon Bedrock.
- Fixed intents are telemetry or optimization hints only, never a capability gate or sole execution path.
- Planner-selected categories map only to application-owned allowlisted read collectors; chat cannot execute writes.
- Missing optional evidence is represented as `missing_data`, not an exception.
- Deterministic code owns scores, calculations, eligibility, and candidate ranking.
- Preserve `read degraded; write closed` and the structured Jira reassignment saga.
- Use one correlation ID across planning, collection, derivation, generation, grounding, and response.

```python
class EvidencePlan(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)
    scope: EvidenceScope
    entities: tuple[EvidenceEntity, ...] = ()
    evidence_categories: tuple[EvidenceCategory, ...]
    exhaustive: bool = False


def calculate_capacity(
    configured_capacity_hours: float, workload_hours: float
) -> CapacityEvidence:
    if configured_capacity_hours <= 0:
        raise ValueError("configured capacity must be positive")
    headroom = configured_capacity_hours - workload_hours
    return CapacityEvidence(
        configured_capacity_hours=configured_capacity_hours,
        workload_hours=workload_hours,
        available_capacity_hours=max(headroom, 0),
        capacity_headroom_hours=headroom,
        utilization_percent=workload_hours / configured_capacity_hours * 100,
    )
```
