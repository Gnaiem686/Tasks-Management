# PostgreSQL connectivity failure

1. Confirm RDS health, security-group paths, DNS, credentials delivery, and pool saturation.
2. Keep persisted workflows closed: do not create, approve, or execute proposals.
3. Allow only clearly labeled, confidence-permitted read degradation from fresh evidence.
4. Never bypass transactional persistence or write audit data to logs as a substitute.
5. Resolve after connectivity and a safe transaction probe recover in the affected environment.
